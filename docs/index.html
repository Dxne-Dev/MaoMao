Un compagnon discret au sommet de votre écran

MaoMao surveille en temps réel vos sessions d'agents IA, valide les permissions en un clin d'œil et garde le contact avec vos déploiements et services cloud — sans jamais quitter votre espace de travail.

→ Télécharger pour Windows & Mac Voir sur GitHub

Gratuit · Aucun compte requis · Vos clés restent sur votre machine

Compatible avec : ⚡ Claude Code 🤖 OpenAI Codex 🚀 Antigravity 💻 Cursor ✨ Gemini CLI 🪟 Windows 10/11 🍏 macOS 15+

Conçu pour vos flux de travail IA

Chaque détail a été pensé pour vous faire gagner du temps et vous offrir une visibilité instantanée.

Interface

HUD & Dynamic Island

Se loge parfaitement dans l'encoche de votre MacBook ou flotte élégamment en haut de votre écran Windows sous forme d'îlot dynamique interactif.

Temps Réel

Suivi des Agents IA

Détection automatique des sessions Claude Code, Codex, Antigravity, Cursor et Gemini. Observez leurs étapes, leurs réflexions et leurs coûts sans encombrer votre terminal.

Contrôle

Validation en 1 Clic

Approuvez ou refusez les demandes de permission (commandes bash, écriture de fichiers) directement depuis l'îlot, sans changer d'application ni perdre le focus.

Productivité

Glisser-Déposer Instantané

Déposez n'importe quel fichier, capture d'écran ou document sur MaoMao pour déclencher immédiatement une analyse IA ou une transcription OCR.

Sécurité

100% Local & Privé

Aucun compte, aucun serveur distant, zéro pistage. Vos clés API restent sécurisées dans le Windows Credential Manager ou le trousseau macOS.

Performance

Ultra Léger & Fluide

Construit en Rust avec Tauri v2. Moins de 30 Mo de RAM, démarrage instantané et animations à 60 FPS sans ralentir votre machine.

git clone https://github.com/Dxne-Dev/MaoMao.git
cd MaoMao/windows
npm install
npm run tauri dev

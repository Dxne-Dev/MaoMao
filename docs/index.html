Un compagnon discret au sommet de votre écran

MaoMao surveille en direct vos sessions d'agents IA (Claude Code, Codex, Antigravity, Cursor...), valide les permissions en 1 clic et garde un œil sur vos déploiements et services cloud sans jamais quitter votre espace de travail.

Tout ce dont vous avez besoin sous les yeux

Pensé pour les développeurs, les makers et tous ceux qui collaborent quotidiennement avec des agents IA.

HUD & Dynamic Island

Se loge parfaitement dans l'encoche de votre MacBook ou flotte discrètement en haut de votre écran Windows sous forme d'îlot dynamique interactif.

Suivi Agents IA en direct

Détection automatique des sessions Claude Code, OpenAI Codex, Google Antigravity, Cursor et Gemini CLI. Visualisez les pensées, les outils appelés et les coûts.

Validation en 1 Clic

Approuvez ou refusez les demandes de permission (exécution de commandes bash, modifications de fichiers) directement depuis l'îlot sans changer d'onglet.

Glisser-Déposer Instantané

Glissez n'importe quel fichier ou capture d'écran sur MaoMao pour déclencher instantanément une analyse intelligente ou une transcription OCR.

100% Privé & Sécurisé

Aucun compte, aucun serveur tiers, aucune télémétrie. Vos clés API sont stockées dans le Windows Credential Manager ou le trousseau macOS.

Ultra Léger & Réactif

Construit avec Tauri v2 et Rust, MaoMao consomme moins de 30 Mo de RAM et offre un taux de rafraîchissement fluide à 60 FPS.

Connectez tous vos outils de développement

MaoMao interroge vos services en tâche de fond et affiche les alertes critiques dès qu'elles surviennent.

Installer MaoMao

Téléchargez le binaire précompilé ou compilez depuis les sources.

Option 1 — Téléchargement direct (Releases GitHub)

Rendez-vous sur la page des releases pour télécharger l'installateur adapté à votre système d'exploitation :

Accéder aux Releases GitHub →

Option 2 — Compiler depuis les sources

# Cloner le dépôt
git clone https://github.com/Dxne-Dev/MaoMao.git
cd MaoMao/windows

# Installer les dépendances et lancer en mode dev
npm install
npm run tauri dev
